# JA-like AI Prototype

Небольшой самостоятельный тактический прототип в духе Jagged Alliance 2. Движок Godot 4.7.2, полноценная 3D-сцена, процедурная геометрия. Это демонстрация направления, а не порт движка JA2 и не законченный ремейк.

[Скачать сборку Windows](https://github.com/Kpoji4er/ja-like-ai-prototype/releases/latest) · [Исходники](https://github.com/Kpoji4er/ja-like-ai-prototype)

**Задача:** за одну ночь получить запускаемую демонстрацию «вайб JA2, но в 3D»: пыльная Омерта, отряд A.I.M., изометрическая камера с вращением, пошаговая перестрелка и захват сектора.

## Запуск

Скачайте ZIP из раздела **Releases**, распакуйте целиком и дважды нажмите `START.cmd`. В архиве движок уже лежит в `tools/godot`; устанавливать редактор не требуется. Для работы используется 64-битная Windows и видеокарта с Vulkan. При проблемах можно запустить из PowerShell:

```powershell
.\launch.ps1 --rendering-method gl_compatibility
```

Для показа на другом ПК достаточно скопировать распакованную папку сборки. Оригинальная JA2, интернет, Python и редактор Godot для игры не нужны. Сборка проверена запуском на текущем ПК; другой компьютер пока не проверялся.

Если вы скачали **исходники**, сначала выполните `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-godot.ps1`, затем запустите `START.cmd`. Скрипт скачивает закреплённую версию Godot 4.7.2 внутрь проекта. Также можно открыть `game/project.godot` в установленном Godot 4.7.2.

## Управление

- ЛКМ по бойцу или 1/2/3 — выбрать наёмника.
- ЛКМ по земле — движение по показанному маршруту; 2 ОД за клетку.
- ЛКМ по противнику — выстрел; 6 ОД, попадание вероятностное.
- F — прицеливание: выстрел за 8 ОД, повышенная точность.
- C — присесть/встать за 2 ОД; влияет на точность и уязвимость.
- Пробел — передать ход противнику, затем восстановить ОД отряда.
- WASD — перемещение камеры; Q/E — поворот; колесо — масштаб.
- Home — исходный вид; Tab — следующий живой наёмник.
- F2 — скрыть интерфейс и маркеры для фото; F12 — `build/screenshot.png`.

## Что реализовано

Один сектор 32×26 клеток, три бойца и четыре противника. Маршруты обходят здания, укрытия и живых персонажей. Здания блокируют линию огня. Низкие укрытия снижают шанс попадания только с соответствующей стороны. Противник выбирает позицию и стреляет. Есть здоровье, смерть, победа и поражение, перезапуск операции, мини-карта, звук выстрела.

Визуал: дома с черепичными крышами и ставнями, клиника, дорожные знаки, старые машины, провода, водонапорная башня, пальмы и кустарник. Всё построено программно, внешние игровые ассеты не требуются.

## Границы прототипа

Нет оригинальных карт, кампании, диалогов, инвентаря, сохранений, разрушаемости, входа в здания, тумана войны и анимационного скелета. Противники видны на карте с начала операции. Механика упрощена; это не точное воспроизведение формул JA2. Персонажи и окружение пока процедурные.

## Файлы

- `game/main.gd` — бой, навигация, камера, интерфейс.
- `game/world.gd` — окружение и персонажи.
- `game/ground.gdshader` — поверхность дороги и грунта.
- `game/minimap.gd` — мини-карта.
- `tools/` — загруженный движок.
- `.runtime/` — перенаправленные TEMP, TMP, APPDATA, LOCALAPPDATA дочернего процесса.
- `game/.godot/` — кэш проекта Godot.
- `build/` — журналы и снимки.

Все явно создаваемые загрузки, кэши и результаты работы размещаются внутри папки проекта. Скрипт запуска меняет переменные среды только своего процесса и его дочернего движка, не системные настройки Windows.

## Проверки

```powershell
.\launch.ps1 --headless -- --test
.\launch.ps1 -- --capture
```

Результат последней полной автоматической проверки сохранён отдельно в `build/tests.log`. Обычный запуск пишет `build/game.log`; команда захвата сохраняет реальный кадр в `build/preview.png`.

Пройденный сценарий: маршрут в обход препятствий → списание ОД → приседание → выстрел → четыре противника выполняют свой ход → восстановление ОД → добивание последней цели → победа → реальная перезагрузка сцены и проверка исходного состояния. Звук отключён только в headless-тестах. Визуально проверены основной вид и интерфейс; управляемые игроком длительные прохождения ещё не проводились.
