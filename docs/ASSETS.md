# Источники графических материалов

Геометрия окружения, персонажей и эффектов создаётся программно в проекте.

Использованы бесшовные PBR-текстуры ambientCG, лицензия **CC0 1.0 Universal**:

- [Ground037](https://ambientcg.com/view?id=Ground037) — `game/assets/textures/ground-color.jpg`, `ground-normal.jpg`.
- [Plaster001](https://ambientcg.com/view?id=Plaster001) — `game/assets/textures/plaster-color.jpg`, `plaster-normal.jpg`.

Загружены 15.10.2026 из официальных архивов `1K-JPG`. В игру включены цветовые карты и нормали OpenGL; файлы скопированы без изменения содержимого.

[Условия лицензии ambientCG](https://docs.ambientcg.com/license/) разрешают использование и распространение исходных файлов в играх. [Полный текст CC0](https://creativecommons.org/publicdomain/zero/1.0/legalcode).

Godot распространяется по MIT; текст и уведомления о сторонних компонентах находятся рядом в `godot-license.txt` и `godot-third-party-notices.txt`.
